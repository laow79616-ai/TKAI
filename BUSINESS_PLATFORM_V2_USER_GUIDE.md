# TKAI Business Platform V2 User Guide

Start the platform, open `http://127.0.0.1:4173`, and sign in with an administrator
created through the local bootstrap process. Navigation provides Home, Accounts,
Browsers, Proxies, Tasks, Content, Data, AI Studio, Enterprise Admin, Audit, Health,
Diagnostics, and Settings. Lists are tenant/workspace scoped. Search by ID or name
and filter by module, kind, or status. Archive removes a record from active lists
without destroying history. Exports contain metadata only and redact secret-like
fields. Task and publishing records are reviewable references and never execute.
