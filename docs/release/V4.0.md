# TKAI V4.0.0

Release date: 2026-07-28

Package version: `4.0.0`

Tag: `v4.0.0`

## Overview

TKAI V4.0.0 delivers the TikTok Cloud Control Platform as an offline-testable,
local Windows control plane. It integrates account and browser operations,
proxy configuration, AI-assisted content and operational workflows, bounded
publishing and interaction services, risk controls, analytics, local runtime
management, and operator-facing web applications.

## Local Windows deployment

The supported native workflow uses `scripts/setup-tkai.ps1`,
`scripts/start-tkai.ps1`, `scripts/status-tkai.ps1`,
`scripts/health-tkai.ps1`, and `scripts/stop-tkai.ps1`. The API, Dashboard, and
AI Studio bind to `127.0.0.1` by default. Runtime state remains under the
repository-local `runtime` directory. See [Local Runtime](../LocalRuntime.md)
and [TikTok Local Operations](../tiktok/V4.0-Local-Operations.md).

## Dashboard and AI Studio

The Dashboard provides operational status and TikTok control surfaces. AI
Studio provides the local AI-assisted content and workflow experience. Both
frontends are built from lockfiles and shipped as production bundles in the
release archive.

## Risk controls and security defaults

Risk controls apply explicit limits, approvals, pauses, recovery states, and
audit-oriented decisions. Native local configuration rejects public bindings,
paths outside the repository, duplicate or privileged ports, and embedded
database passwords. Release packaging excludes secrets, runtime data, user
databases, browser profiles, cookies, sessions, proxy credentials, logs,
backups, dependency trees, and temporary or private media.

## Workflow orchestration and operations

The Workflow Orchestration Center coordinates bounded, auditable TikTok module
workflows with approvals, schedules, queues, variables, checkpoints, recovery,
and rollback contracts. The Operations Command Center consolidates module
health, tasks, incidents, alerts, activity, and recovery signals.

## Analytics

The Analytics Center supplies local datasets, KPIs, trends, comparisons,
forecasts, reports, exports, and operational insights without requiring live
TikTok access during automated validation.

## Backup and restore

Local backups include the SQLite database, sanitized configuration, runtime
metadata, an optional media filename manifest, and SHA-256 integrity metadata.
Restore validates integrity, requires stopped services and explicit
confirmation, takes a safety backup, preserves the configured external secret
provider reference, and records an audit event.

## Validation summary

The V4 release gate covers Ruff, mypy, full pytest, TikTok regression tests,
deployment and release tests, local-runtime tests, Dashboard and AI Studio
production builds, PowerShell parsing, OpenAPI uniqueness, database
initialization, backup and restore, package exclusions, checksums, bounded
secret scanning, and native Windows smoke testing. Automated tests do not
require live TikTok credentials or perform real TikTok automation.

## Upgrade

1. Stop TKAI and verify shutdown status.
2. Create and verify a local backup.
3. Retain the previous release archive and configuration for rollback.
4. Update to `v4.0.0`.
5. Compare local configuration with `configuration/local.example.json`.
6. Run `scripts/setup-tkai.ps1`, the release validation gates, and the local
   smoke test.
7. Confirm `/health`, `/readiness`, and `/tiktok/system/health` before use.

## Rollback

Stop TKAI, restore the previous application release, and use
`scripts/restore-tkai.ps1` with a verified explicit backup. Re-run health and
readiness checks before resuming local operations. Detailed operator guidance
is in [TikTok Local Operations](../tiktok/V4.0-Local-Operations.md).

## Known limitations

- The supported deployment profile has a local single-user focus.
- Automated tests have no live TikTok dependency.
- TKAI provides no CAPTCHA bypass.
- TKAI provides no restriction circumvention.
- TKAI provides no security bypass.
- TKAI provides no anti-detection guarantees.
- Browser automation requires locally supported runtime configuration.
- Docker Compose CLI validation requires Docker installation.
- External proxy health depends on user configuration.
- Real TikTok credentials and real TikTok automation are outside automated
  acceptance and release validation.
