# TKAI V1.2 RC-1 integration baseline

Version `1.2.0rc1` establishes an offline integration and compatibility
baseline. Policy, Retry, Distributed Runtime, Telemetry, Adaptive Routing, and
Multi-region Routing are additive, explicitly constructed services; none takes
over AIClient, ProviderManager, or Runtime defaults.

## Compatibility

V1.1 public imports and legacy CLI commands remain available. New APIs are
exported only from their new module packages. Empty and legacy configuration
continue to resolve to the same defaults, while explicit configuration remains
an opt-in overlay.

## Lifecycle and failure isolation

Local `start`, `stop`, and `shutdown` operations are idempotent where exposed.
Optional exporter, policy, retry, region, and EventBus subscriber failures are
isolated from primary control flow. No service makes network calls during import,
diagnostics, or baseline validation.

## Known limitations

All V1.2 foundations remain process-local and in-memory. There is no Redis,
cluster coordination, automatic failover, traffic migration, active health
probe, machine-learning routing, OpenTelemetry SDK, or distributed telemetry.
