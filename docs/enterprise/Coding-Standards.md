# Coding Standards

Python targets 3.10+, UTF-8, four spaces, type annotations, public docstrings, and configured Ruff style. Prefer cohesive modules, explicit errors, deterministic tests, managed resources, and secret-free structured logs. Avoid mutable globals, hidden network calls, broad exception suppression, and imports bypassing public contracts. Frontend code must pass TypeScript, lint, and production builds. Localized exceptions require explanation.
