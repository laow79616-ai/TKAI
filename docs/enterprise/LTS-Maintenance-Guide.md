# LTS Maintenance Guide

LTS is explicitly designated in metadata/notes with owner, support dates, runtime matrix, severity policy, and successor. Only security, critical reliability, compatibility, documentation, and release-engineering fixes enter `support/<major>.<minor>`; no features enter patches. Fixes are reviewed, validated, patched, and merged forward. Announce end-of-support with migration guidance and retain tags, checksums, advisories, and evidence.
