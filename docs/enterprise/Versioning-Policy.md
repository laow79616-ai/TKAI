# Versioning Policy

TKAI uses Semantic Versioning and tags `vX.Y.Z`. MAJOR is an approved incompatible contract change, MINOR a backward-compatible capability release, and PATCH a backward-compatible fix or lifecycle change. Productization after 12.0.0 uses a future patch and never rewrites 12.0.0. Python, dashboard, Studio, Helm, metadata, notes, tag, and artifact versions MUST agree. Release candidates use identifiers such as `12.0.1-rc.1`.
