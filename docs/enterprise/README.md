# TKAI Enterprise Product Baseline

This set governs TKAI 12.x as an enterprise product. It adds no framework capability and does not change runtime, TikTok, API, or OpenAPI behavior.

## Guides

Enterprise Architecture, Developer Handbook, Contribution Guide, Coding Standards, Release Process, Versioning Policy, Branch Strategy, Security Handbook, Operations Handbook, Deployment Handbook, Administrator Guide, User Guide, API Reference Index, OpenAPI Guide, Testing Guide, Troubleshooting Guide, LTS Maintenance Guide, and Local Setup Guide are maintained in this directory.
