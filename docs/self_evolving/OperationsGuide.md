# Operations Guide

Monitor profile health, evolution progress, learning cycles, failures, resource usage, latency, rollbacks, and audit volume through the dashboard and Prometheus endpoint. On unacceptable risk, activate the kill switch, investigate audit and monitoring records, roll back to a verified ancestor version, validate safety and regression results, then release the switch under human oversight.

The API exposes profiles, evolution, learning, experiments, optimization, monitoring, and metrics below `/self-evolving`. Run Ruff, mypy, pytest, deployment and release suites, dashboard and AI Studio production builds, and `git diff --check` before release.
