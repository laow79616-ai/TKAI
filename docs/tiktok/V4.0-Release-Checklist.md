# V4.0 release checklist

- [ ] Worktree is clean and version is 4.0.0.
- [ ] Ruff, mypy, full pytest, TikTok regression, deployment, release, and local-runtime tests pass.
- [ ] Dashboard and AI Studio production builds pass.
- [ ] PowerShell scripts parse successfully.
- [ ] OpenAPI generates with unique routes.
- [ ] Temporary database initialization, backup, and restore pass.
- [ ] Startup, repeated startup, shutdown, repeated shutdown, health, and diagnostics pass.
- [ ] Release archive builds; content exclusions and SHA-256 checksums validate.
- [ ] Bounded secret scan and `git diff --check` pass.
- [ ] Rollback commit and verified backup are recorded.

If any mandatory item fails, do not distribute the package. Follow the rollback
guide in `V4.0-Local-Operations.md`, preserve runtime data, and diagnose the failure.
