# Analytics

The scoped analytics response reports collection volume, successful tasks,
failed tasks, dataset growth, pipeline runtime, and project count. The dashboard
adds job, dataset, pipeline, history, and metric summaries.

Prometheus metrics are `tiktok_collection_projects_total`,
`tiktok_collection_jobs_total`, `tiktok_collection_success_total`,
`tiktok_collection_failure_total`, `tiktok_dataset_total`, and
`tiktok_collection_latency_seconds`.
