# Knowledge Evolution

Evolution reads the selected source snapshots for a bounded subject, preserves
their summaries and integrity references as evidence, calculates the arithmetic
mean confidence, and creates an immutable numbered version. Each version explains
how many source snapshots it synthesized and links to the preceding version.

The timeline contains version, comparison, and recommendation events scoped to
the requesting tenant and workspace. It is explainable history, not an operations
queue. Nothing in the timeline can trigger an action.
