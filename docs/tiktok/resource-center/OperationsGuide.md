# Operations Guide

Use the dashboard for inventory, allocations, reservations, leases, capacity,
utilization, health, recovery, and statistics. Run reconciliation after an
unclean shutdown and investigate expired ownership records or degraded health.
Scale only by configuring supported local resources. Never log secrets, weaken
approval rules, or retry a resource with an unresolved TikTok challenge.

For incidents: pause the owning resource, inspect the existing Risk and Operations
Centers, resolve the supported condition, reconcile inventory, then initiate one
bounded recovery. Archive resources that are no longer available.
