# Operations Guide

Use the dashboard for scoped overview and API resources for detailed records.
Investigate any safety-state analysis stop in the Risk Control, Control Tower,
Runtime, or source module. Review objectives, bounds, evidence, risk, and
confidence before approval. Revoke or allow approvals to expire instead of
editing approved records. Handoffs should be traced by their accepted reference
in the existing downstream center. Metrics and history provide local audit and
health signals.
