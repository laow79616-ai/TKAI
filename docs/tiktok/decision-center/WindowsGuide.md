# Windows Guide

From PowerShell in the repository, use `scripts\start-tkai.ps1` and
`scripts\status-tkai.ps1` for the loopback-only local runtime. Open the dashboard
and select `tiktok-ai-intelligent-decision-center`. Use
`scripts\stop-tkai.ps1` to stop services. No live TikTok access is required for
Decision Center tests; all tests use deterministic mocks.
