# Operations Guide

1. Provision agents with least-privilege capabilities and advance them to Ready.
2. Create a team with exactly scoped members and a coordinator.
3. Validate plans, risks, resources, dependencies, retries, and approvals.
4. Coordinate assignments and review any unresolved capability conflicts.
5. Execute, observe health and metrics, and investigate failures through audit.
6. Pause unsafe agents, restore checkpoints, or escalate to a supervisor.
7. Archive completed agents and retain memory according to policy.

Scrape `/multi-agent/metrics`, monitor `/multi-agent/monitoring`, and use the
dashboard for agents, teams, coordination, execution, planning, consensus,
negotiation, memory, knowledge, and health.
