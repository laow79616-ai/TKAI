# Operations Guide

The GET-only projections are:

- `/v7/security/policies`
- `/v7/security/roles`
- `/v7/security/permissions`
- `/v7/security/authorization`
- `/v7/security/compliance`
- `/v7/security/secrets`
- `/v7/security/audit`
- `/v7/security/health`
- `/v7/security/metrics`

Monitor degraded health, policy conflict and denial counters, validation failures,
secret rotation dates, and audit continuity. No endpoint mutates policy or secret
state.
