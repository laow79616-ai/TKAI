# Operations Guide

Register resource type contracts, then immutable resource records. Discover
records by type, category, owner, capability, dependency, tags, or indexed
metadata. Validate before consuming capacity, reservation, allocation, or
recovery plans. Monitor the read-only dashboard and GET API projections for
health, metrics, and audit data.

Treat every output as advisory. Runtime control belongs to existing,
independently authorized systems. Back up metadata through external persistence
adapters; this framework's default registry is process-local.

For incidents, mark lifecycle metadata unavailable, create a reference-only
recovery or rollback plan, review dependencies and capacity, and pass the plan
to the authorized recovery coordinator.
