# Extension Model

An extension manifest contains extension ID, name, description, category,
owner, semantic version, scope, plugin IDs, compatibility, dependencies,
permissions, capabilities, interfaces, status, lifecycle, safe metadata,
health, metrics, audit references, sandbox metadata, package metadata,
signature metadata, and timestamps.

Lifecycle states are discovered, registered, validated, compatible, available,
disabled, deprecated, retired, and archived. Transitions are explicitly
allowlisted. Registration never activates executable code.
