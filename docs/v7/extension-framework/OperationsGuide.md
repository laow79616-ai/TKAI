# Operations Guide

Compose immutable manifests locally, register prerequisite extensions, register
declared plugins, validate records, resolve dependencies, check compatibility,
and inspect read-only dashboard or API projections. Only promote lifecycle
states through the allowlisted transitions.

Monitor `v7_extension_*` metrics, health metadata, structured trace hooks, and
scope-filtered audit records. A failed permission or isolation check increments
the security rejection metric. Deployment, enablement, installation, migration,
and runtime execution remain separate operational responsibilities.
