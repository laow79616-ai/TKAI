# Operations Guide

Use the GET-only `/v7/runtime-governance/*` projections to inspect profiles,
policies, eligibility, runtime references, pause declarations, kill-switch
declarations, diagnostics, health, and metrics. Always treat eligibility,
readiness, review, and approved-reference values as advisory metadata.

The framework preserves V6 behavior through read-only references. It needs no
TikTok account, browser, cookie, session, proxy, cloud service, or live runtime.
