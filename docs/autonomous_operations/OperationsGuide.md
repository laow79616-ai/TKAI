# Operations Guide

1. Create an operation in Draft.
2. Attach weighted objectives, versioned policies and strategies.
3. Configure tasks, dependencies and safety limits.
4. Advance to Ready; approve supervised execution.
5. Monitor dashboard state, audit and Prometheus metrics.
6. Pause or activate the kill switch on unsafe behavior.
7. Review feedback, run optimization and adaptation, then version a learning cycle.
8. Use rollback checkpoints for recovery and archive completed operations.
