# Operations Guide

Monitor the seven `autonomous_*` metrics and the monitoring dashboard. Alert on
degraded health, rising latency, execution failures, or falling confidence.
Pause a running profile before investigation. Use checkpoint rollback for
unsafe outcomes, recover only after policy approval, and archive completed
profiles according to tenant retention policy.

Deploy as part of the existing Docker, Kubernetes, CI/CD, and observability
stack. No new runtime dependency or secret is required.
