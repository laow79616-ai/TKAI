# Operations Guide

Monitor the seven `super_*` metrics and the monitoring dashboard. Alert on
degraded health, rising latency, failures, or falling capability trends. Pause
a running profile before investigation and retain audit, evidence, world-model,
and decision-trace references. Archive completed profiles according to tenant
retention policy and delete only from Archived.

Deploy as part of the existing Docker, Kubernetes, CI/CD, and observability
stack. No new runtime dependency or secret is required.
