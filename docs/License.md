# TKAI Enterprise License Foundation

License Foundation supplies immutable editions, capabilities, feature,
entitlement, validation, expiration, grace-period, and renewal descriptors.
`ReferenceLicenseService` returns only explicitly injected in-memory
entitlements. It never controls Platform features.

There is no online activation, license server, signature validation, key
management, license-file read, Runtime/SDK/Studio hook, feature enforcement,
authentication, billing, cloud integration, persistence, or network access.
