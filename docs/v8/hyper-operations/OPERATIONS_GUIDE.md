# Operations Guide

Create immutable records, register them with `HyperOperationsFabric`, and consume `snapshot()`, `health()`, `metrics()`, the read-only dashboard projection, or the nine GET API projections.

Investigate `required-dependency-unavailable` diagnostics before treating a subject as ready. Readiness never grants execution eligibility.

Only `v6-ai-centers`, `v7-frameworks`, and `v8-frameworks` are accepted by the bounded aggregation adapter.
