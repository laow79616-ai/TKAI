# Hyper Knowledge Fabric

A knowledge profile identifies its version and owner and references frameworks,
knowledge, ontology, evidence, relationships, compatibility, and governance.
Health, metrics, audit records, isolation scope, lifecycle, and secret-filtered
metadata complete the profile.

`HyperKnowledgeFabric.aggregate_metadata` normalizes V6 AI Center, V7 framework,
and V8 framework references into a unified projection without touching the
source runtimes. Registrations are deterministic and duplicate identifiers are
rejected.
