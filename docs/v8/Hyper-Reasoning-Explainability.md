# Hyper Reasoning Explainability

Explainability uses short, safe summaries plus evidence, assumption, policy,
decision, and limitation references. Summaries describe the supported outcome
without exposing private model deliberation.

Chain-of-thought, hidden reasoning, internal reasoning, scratchpads, reasoning
traces, and thought logs are prohibited from metadata and are not persisted.
There is no chain-of-thought retrieval endpoint. Explanations are advisory and
must not be interpreted as action authorization.
