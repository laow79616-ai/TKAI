# Framework Registry

The registry recognizes Foundation, Capability, Service Mesh, Event Fabric,
State, Workflow, Resource, Security, Observability, Configuration, Extension,
AI, Data, Intelligence, Runtime Governance, and Future framework kinds.

Records contain identifier, version, kind, isolation scope, dependency
references, capability names, lifecycle label, published health, and immutable
metadata. Unknown framework families must register as `future`. Duplicate
identifiers are rejected within the same tenant/workspace/framework scope.
