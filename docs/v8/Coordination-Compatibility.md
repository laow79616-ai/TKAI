# V8 Coordination Compatibility

Feature 2 is additive under `tkai.v8.hyper_coordination`. Existing V6, V7, and
V8 Hyper Kernel imports and behavior remain unchanged. Default descriptors
cover V6 AI Centers, V7 frameworks, the V8 Hyper Kernel, and future frameworks.

Compatibility edges express metadata claims only. They do not load, modify, or
invoke the referenced systems.
