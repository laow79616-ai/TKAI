# Hyper Reasoning Compatibility

Reasoning references and compatibility records support V6, V7, and V8
generation labels. Existing V6 AI Center, V7 Framework, and V8 Framework APIs
remain unchanged; the fabric imports none of their runtime implementations and
uses reference descriptors only.

Compatibility records link a source and target, status, notes, scope, and
metadata. Cross-version aggregation is additive and does not change legacy
registries or lifecycle behavior.
