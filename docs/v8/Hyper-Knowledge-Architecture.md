# Hyper Knowledge Architecture

TKAI V8 Hyper Knowledge is an advisory, metadata-only fabric spanning V6 AI
Centers, V7 frameworks, and V8 frameworks. Its composition root owns local,
in-memory projections of immutable profiles, ontology concepts, entities,
relationships, evidence provenance, lineage, and compatibility records.

The fabric stores references, never referenced payloads. It performs no graph
execution, TikTok action, runtime mutation, policy enforcement, or automatic
decision. Existing V6 and V7 components remain owners of their data and require
no code changes.

The layers are contracts, normalization, deterministic registries, fabric
services, security and observability projections, dashboard snapshots, and
GET-only transport adapters. Optional FastAPI hosting is isolated at the API
edge.
