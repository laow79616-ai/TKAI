# Hyper Intelligence

`HyperIntelligenceFabric` is the composition root. A profile identifies its
version and owner and links to frameworks, AI Centers, knowledge, evidence,
signals, and compatibility metadata. Health, metrics, audit, and arbitrary
secret-filtered metadata complete the profile.

Recommendations are advisory. Profiles, lifecycle states, governance references,
and recommendations always report that execution is unauthorized. The fabric
does not execute TikTok actions, mutate runtime state, or approve execution.
