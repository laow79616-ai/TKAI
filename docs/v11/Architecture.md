# TKAI V11 Architecture

TKAI V11 adds a unified, local-first intelligence-reference layer above the V10
Sovereign platform. The `AutonomousIntelligenceCore` combines immutable profile,
scope, cross-version, health, metric, audit, and domain-reference projections.
It is advisory, deterministic, read-only, and free of runtime action paths.

The core references the V10 Sovereign Core and its trust, integrity, governance,
compatibility, knowledge, reasoning, decision, planning, operations, and recovery
meshes. V6 through V10 remain supported; no prior package or route is replaced.
