# Autonomous Intelligence Core

`AutonomousCoreModel` is frozen metadata containing the core ID, V11 version,
intelligence profile, domain references, validation and diagnostic references,
health, metrics, audit references, safe metadata, and isolation scope.

`AutonomousIntelligenceCore` only serializes and projects this model. It has no
registration, execution, scheduling, allocation, deployment, storage, browser,
account, TikTok, configuration, or service-control operation.
