# API

The API exposes thirteen GET-only routes:

- `/v11/graph`
- `/v11/graph/profile`
- `/v11/graph/nodes`, `/edges`, `/relationships`, and `/dependencies`
- `/v11/graph/taxonomy` and `/ontology`
- `/v11/graph/validation` and `/diagnostics`
- `/v11/graph/health`, `/metrics`, and `/audit`

POST, PUT, PATCH, and DELETE are absent. There are no action, browser, TikTok,
execution, mutation, planning, scheduling, allocation, deployment, recovery, or
control endpoints.
