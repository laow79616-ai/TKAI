# Operations Guide

Monitor `/v9/intelligence/health` and `/v9/intelligence/metrics`; inspect
diagnostics and audit projections when reference coverage degrades. All public
mesh endpoints use GET. There is no execution, mutation, TikTok action, hidden
reasoning, or chain-of-thought endpoint.

Run Ruff, configured mypy, Python test suites, operational PowerShell checks
under `scripts/`, frontend builds, OpenAPI validation, and `git diff --check`.
