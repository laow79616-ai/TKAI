# Adaptive Intelligence Mesh Architecture

TKAI V9 places a metadata-only federation layer above V6 AI Centers, V7
frameworks, V8 frameworks, and V9 components. The mesh stores immutable
descriptors and references, never source payloads or runtime adapters.

The composition root owns scoped registries, reference aggregation,
relationships, health, metrics, diagnostics, structured logs, traces, and
audit records. Transport adapters are projections over local metadata and
cannot invoke TikTok or mutate a referenced runtime.
