# Adaptive Governance Mesh

The mesh is an advisory, metadata-driven federation layer. It standardizes
governance discovery across TKAI generations while retaining the V6, V7, and
V8 public APIs unchanged.

All records are immutable. Approval means only that approval metadata was
recorded; `execution_authorized` is always false. Policy and compliance
records are descriptive and cannot enforce runtime behavior or execute TikTok
actions.
