# Sovereign Knowledge Mesh Architecture

The TKAI V10 Sovereign Knowledge Mesh is a local-first reference layer over
explicitly supplied metadata for completed V6 through V10 components.

Immutable contracts feed bounded, tenant/workspace-isolated in-memory registries.
The query layer reads only those registries. Dashboard projections and ten
GET-only API routes expose filtered metadata, health, and metrics.

The mesh never scans repositories, ingests production data, invokes external
search, executes TikTok actions, learns automatically, or mutates runtime state.
References do not imply authorization, trust, compatibility, or verification.
