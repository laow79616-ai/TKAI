# Self-Optimization Architecture

The platform is a framework-neutral, in-memory reference control plane. Profiles
scope every operation to a tenant and workspace. Typed records feed optimization,
resource, performance, cost, latency, capacity, experiment, recommendation,
evaluation, and monitoring domains. API and dashboard adapters expose read models.

All mutations pass RBAC, scope isolation, validation, audit, and kill-switch checks.
This package composes beside existing TKAI platforms and does not alter their APIs.
