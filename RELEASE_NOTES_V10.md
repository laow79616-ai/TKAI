# TKAI 10.0.0 Release Notes

TKAI V10 is a compatibility-preserving platform release comprising exactly 11
sovereign components. V10 endpoints remain authenticated, advisory, and
GET-only. This release adds no TikTok business behavior, execution capability,
runtime mutation, automatic migration, approval, trust grant, or recovery
execution.

V6, V7, V8, and V9 APIs and Dashboard, AI Studio, local runtime, deployment,
configuration, storage, extension, security, and OpenAPI behavior remain
available. Python 3.10 or newer is required. Node.js 18 or newer is required
for frontend builds; PowerShell 7 is recommended for Windows operations.

No final tag is created by the production-readiness feature. Operators must
back up configuration and storage, validate the generated manifest and
checksums, and complete deployment-specific acceptance checks before tagging.
