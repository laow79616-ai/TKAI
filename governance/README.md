# Enterprise AI Governance Platform

`governance` provides transport-neutral policy, risk, control, approval,
resource-governance, incident, exception, evidence, reporting, and dashboard
services. All records are tenant- and workspace-scoped. The optional API
adapter registers `/governance/*` routes without adding FastAPI to the core
dependency set.

Framework mappings, assessments, evidence, and attestations are governance
workflow records only. They do not claim certification or legal compliance.
