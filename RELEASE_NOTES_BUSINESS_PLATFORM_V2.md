# TKAI Business Platform 2.0.0 Release Notes

Business Platform V2 adds persistent tenant/workspace-scoped management for Account,
Browser, Proxy, Task, Content, Data, AI Studio, and Enterprise Admin centers. It adds
authenticated CRUD/archive APIs, audit history, safe exports, persisted dashboard
metrics, PBKDF2 password verification, secret rejection/redaction, local deployment
guides, acceptance coverage, OpenAPI, and reproducible release manifests. V1 and
TKAI V6-V12 compatibility routes remain available. No live TikTok execution or
restriction-bypass functionality is included.
